# SISGES school portal

The React and TypeScript client serves school administrators, teachers and students. It connects to the SISGES Go API for enrollment, timetable and lesson records, grading, attendance and school communications.

Start with the [technical handbook](docs/README.md) for local setup, product requirements, API contracts, test commands and known integration gaps. Artwork and asset usage are documented with the [brand kit](brand/open-book/README.md).
